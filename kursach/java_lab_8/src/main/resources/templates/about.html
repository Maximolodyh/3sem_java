О приложении

Курсовой проект по Spring Boot — вариант № 1

Книжный каталог

Приложение предназначено для хранения списка книг, книжных магазинов и цен на книги.

Технологии: Java 17, Spring Boot, Spring MVC, Spring Security, Spring Data JPA, Thymeleaf, H2, Actuator.

Разработчик: укажите своё ФИО, учебную группу и год при подготовке пояснительной записки.

Безопасность: пароль сохраняется в виде BCrypt-хеша; данные изменяют только авторизованные пользователи с соответствующими правами.
